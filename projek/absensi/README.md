# Human Resource Management (HRM) - Mobile Application

A Flutter-based Human Resource Management (HRM) mobile application developed as part of a Project-Based Learning (PBL) project at Politeknik Negeri Malang.

The application is designed for employees to manage attendance, leave requests, payroll information, and personal profiles through a mobile platform.

---

## Tech Stack

- Flutter
- Dart
- Laravel REST API
- MySQL
- Firebase Cloud Messaging (FCM)
- Git
- GitHub

---

## Features

- Secure Login
- Attendance (Check In & Check Out)
- Attendance History
- Leave Request
- Payroll Summary
- Employee Profile
